# 20FIN — MVP 기능 명세서

> **20FIN** — 20대의 Life Event를 시간축으로 이해하고, 각 시점에 필요한 금융정보와 다음 행동을 제안하는 Timeline-aware AI 금융 서비스.
> 배포 URL: `<배포 URL 기입>` · 로그인 불필요(브라우저 기반)

---

## 1. MVP 구현 범위

이번 예선 MVP에서 **실제 동작하는** 범위는 다음과 같다.

**구현 완료**
- 온보딩(내 20대 그리기): 기본정보 입력 → Life Event 입력 → 금융 체크포인트(Fin Event) 자동 생성
- 나의 20대(홈): Timeline 시각화 + Right Now 패널(지금 챙길 것 · 곧 다가와요 · 놓치면 아까워요)
- Event 상세(Drawer): Life Event별 준비도·체크리스트·인사이트·AI 연결
- 지금의 기회: 청년정책·LH 주거공고·장학금 **실데이터**를 내 정보 기준으로 개인화 랭킹 + 추천 근거
- AI에게 물어보기(피오): 내 Timeline을 아는 대화형 Agent + 구조화 추천(Decision) 출력
- 내 정보: 프로필·이벤트 확인, 이벤트 추가, 초기화

**구현 범위에서 제외(미구현/향후)**
- 금융 프로필(소득·부채 등) 입력 화면 — 현재는 AI 대화 중 필요 시 사용자에게 질문하는 방식
- 로그인·계정, 서버 영구 저장(DB) — 상태는 브라우저에만 저장(무상태 서버)
- 소비/계좌 연동, 푸시·이메일 알림, 다기기 동기화
- 실시간 데이터의 지역 정밀 타겟팅(현재 광역 지자체 단위)

## 3. 사용자 이용 흐름

배포 URL 접속 후 순서:

1. **접속** → 저장된 정보가 없으면 자동으로 온보딩(`/onboarding`)으로 이동
2. **기본정보 입력** — 나이(슬라이더), 현재 상태(대학생/취업준비/직장인/프리랜서/기타), 거주(본가/기숙사/자취/기타), 지역 → "내 20대 그리기"
3. **Life Event 입력** — 카테고리 선택 → 세부 이벤트 → 연·월 → 확실성 선택 후 추가(1개 이상). 예) 졸업 2027.02(확정), 취업 2027.08(예상), 독립 2028.03(목표)
4. **금융 체크포인트 생성 확인** — 입력을 기반으로 만들어진 Fin Event 미리보기 → "나의 20대 Timeline 보기"
5. **나의 20대(홈)** — Timeline에서 현재 위치와 앞으로의 이벤트, 우측 Right Now에서 지금 챙길 것·임박 마감·1순위 기회 확인
6. **Event 상세** — Timeline 노드(예: 독립) 클릭 → 준비도·체크리스트(완료 체크 시 준비도 즉시 갱신)·인사이트 확인 → "피오에게 물어보기"로 연결
7. **지금의 기회(`/opportunities`)** — 내 정보 기준으로 필터링된 지원정보를 주제별로 확인, 각 카드의 추천 근거·마감(D-day)·"공식 정보 확인하기"
8. **AI에게 물어보기(`/ask`)** — 추천 질문 또는 직접 질문 입력 → 내 Timeline 기반 답변, 선택형 질문은 Decision(추천·비교표·근거) 제공
9. **내 정보(`/me`)** — 프로필 확인, 새 이벤트 추가, 필요 시 초기화

## 4. AI 및 데이터 처리 방식

### AI가 수행하는 역할
- **자연어 응답(피오)**: 사용자 질문에 대해 내 기본정보·Timeline·금융 체크포인트를 근거로 답변 생성
- **구조화 추천(Decision)**: "무엇을 먼저/얼마씩" 같은 선택·배분형 질문에 추천 한 줄 + 전략 비교표 + 근거 목록을 JSON으로 생성 → UI가 표로 렌더
- **가드레일**: 특정 금융상품 가입 권유·투자자문·종목 추천 금지, 컨텍스트에 없는 수치(금액·금리·마감) 날조 금지(부족하면 사용자에게 되물음), 신청·계약·송금은 대신 수행하지 않음
- **모델**: Anthropic Claude(`claude-opus-5`), 서버 라우트 `/api/ask`

> AI에 맡기지 않는 부분(규칙·계산): Fin Event 시점 계산, 준비도(Readiness) 산출, 기회 랭킹(Fit×Timing×Actionability + 지역 판별)은 모두 결정론적 규칙 엔진이 담당한다.

### 사용/입력/출력 데이터
- **외부 데이터 소스(실데이터)**
  - 온통청년 청년정책 API — 실시간 조회(`YOUTH_CENTER_API_KEY`)
  - LH 임대주택 공고(공공데이터포털) — 실시간 조회(`DATA_GO_KR_SERVICE_KEY`)
  - 한국장학재단 장학금 — 실데이터 스냅샷(정적)
- **입력 데이터**: 사용자 기본정보(나이·상태·지역·거주), Life Event(종류·시점·확실성), AI 대화 시 사용자가 직접 제공하는 값(예: 월 가용액)
- **출력 데이터**: Fin Event(체크포인트), Readiness 점수·부족 항목, 개인화 Opportunity 목록 + 추천 근거, AI 답변 + Decision

### 개인정보 / 민감정보 처리
- **로그인·계정 없음.** 사용자 정보(프로필·Timeline·대화)는 **사용 중인 브라우저의 localStorage에만 저장**되며 서버에 영구 저장하지 않는다(무상태 서버).
- `/api/opportunities`, `/api/ask` 호출 시 해당 요청 처리를 위해 필요한 컨텍스트를 서버로 전송하나, 서버는 이를 저장하지 않는다.
- **AI 응답 생성 과정에서 사용자 기본정보·Timeline 컨텍스트가 외부 LLM(Anthropic API)으로 전송**된다.
- 실명·주민등록번호·금융 계좌·카드번호 등 민감 식별정보는 수집하지 않는다.

## 5. MVP 검증 방법

### 확인 절차(배포 URL 기준)
1. 배포 URL 접속 → 온보딩 화면 진입 확인
2. 기본정보 입력(예: **25세 / 취업 준비 / 본가 / 서울**) → "내 20대 그리기"
3. Life Event 3개 이상 추가(예: **졸업 2027.02 확정 / 취업 2027.08 예상 / 독립 2028.03 목표**) → 체크포인트 생성 확인 → Timeline 진입
4. 홈에서 Timeline·Right Now(지금 챙길 것·마감·기회) 노출 확인
5. Timeline의 "독립" 노드 클릭 → 준비도·체크리스트 표시, 체크 시 준비도 갱신 확인
6. `/opportunities` 이동 → 상단 "내 정보 적용 중" 배너와, **입력한 지역(서울)·상태 기준**으로 필터·정렬된 기회·추천 근거 확인
7. `/ask` 이동 → "적금 먼저 할까, 학자금부터 갚을까?" 입력 → 내 Timeline을 반영한 답변 및 Decision(비교표) 확인

### 테스트 입력값 / 예상 결과
- **테스트 계정**: 불필요(로그인 없음)
- **샘플 입력**: 위 2~3단계 값
- **예상 결과**
  - 온보딩 완료 시 입력 이벤트 기반 Fin Event가 자동 생성되어 Timeline·Right Now에 표시
  - `/opportunities`: "서울 거주 관련", "취업 준비 중인 현재 상태와 관련" 등 **내 정보 기반 근거**가 붙은 카드가 상위 노출, 다른 지역 전용 공고는 제외
  - `/ask`: 답변이 사용자 Timeline(예: 2028 독립, 학자금)을 구체적으로 언급, 선택형 질문은 추천·비교표·근거 제공

### 실행 환경 / 브라우저 제한
- 최신 데스크톱/모바일 브라우저(Chrome/Safari/Edge 권장), **JavaScript 및 localStorage 활성화 필요**
- 프라이빗 모드 등 localStorage가 차단된 환경에서는 상태 저장이 되지 않을 수 있음

### MVP 단계 제한사항
- 상태가 **브라우저별 localStorage**에 저장됨 → 다른 기기·브라우저 간 동기화 없음(초기화 시 데이터 삭제)
- **금융 프로필(소득·부채) 전용 입력 화면 미제공** → AI 대화 중 필요 시 사용자에게 질문하는 방식
- 실시간 데이터(청년정책·LH)는 **API 키가 설정된 경우** 동작. 키가 없어도 장학금(실데이터)·Timeline·준비도 등 핵심 기능은 정상 동작
- AI 대화 기능은 `ANTHROPIC_API_KEY`가 설정된 경우 동작(미설정 시 안내 메시지로 대체)
- 지역 필터링은 **광역 지자체 단위**로 판별(시·군·구 세부 매칭은 향후 개선)
- 제공 정보는 관련성 기반 안내이며, 최종 신청 가능 여부·조건은 공식 공고에서 확인 필요
