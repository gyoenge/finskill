# 20FIN Design System · v1.0

2026-09-05 · 브랜딩 및 UI 디자인 기준안

첨부 홈 시안과 현재 서비스 설계를 바탕으로 작성했다. 원본 시안의 이름·날짜·정책·준비도는 예시이며 서비스 데이터가 아니다. 이 패키지는 디자인 기반과 컴포넌트 명세다. 기존 앱에는 아직 적용하지 않았다.

## 1. 브랜드 기반

**20대의 다음을 준비하는 금융.**

사용자의 삶을 기억하고 다음 행동을 함께 준비하는 금융 동반자. 세 가지 성격은 따뜻함, 명료함, 신뢰다. 풍경은 미래의 가능성을, 금융정보는 정확한 현재 상태를 전달한다.

- 서비스명: 20FIN. 한국어 설명에서는 ‘20FIN’으로 통일한다.
- 보조 문구: My 20s, Better Finance.
- 핵심 문장: 지금의 작은 준비가, 더 멋진 20대를 만들어요.
- 행동 언어: 내 20대 그리기 / 새로운 이벤트 추가 / 준비할 일 확인 / 피오에게 물어보기.
- 제품 화면에서는 Life Event → ‘이벤트’, Fin Event → ‘금융 체크포인트’, Readiness → ‘준비도’, Opportunity → ‘지금의 기회’로 표기한다.
- 불안을 부추기는 표현, 근거 없는 낙관, ‘무조건’, ‘완벽한’, ‘반드시 가입’은 사용하지 않는다.
- 관찰 → 이유 → 행동 순서로 쓴다. 예: ‘졸업까지 3개월 남았어요. 상환 일정을 확인하고 생활비 계획을 세워보세요.’

## 2. 로고와 피오

### 워드마크

첨부 시안 기준으로 **20 = Brand Green #20B26B / FIN = Navy #102A43**. 현재 코드의 색 배치는 반대이므로 적용 시 교체한다. 단색 버전은 네이비 또는 흰색이다. 작은 크기에서 장식 새싹은 생략할 수 있다.

- 기본 화면: 높이 28–32px. 최소 높이 20px. 브랜드 보드 48px 이상.
- 보호 공간: 로고 높이의 1/2. 로고 비율·문자 간격은 임의로 늘리지 않는다.
- 태그라인은 로고 아래 8px, 최소 12px. 모바일 내비게이션에서는 생략.
- 제공 SVG는 기존 문자형 워드마크의 정리안이며 최종 커스텀 레터링이 아니다. 폰트 아웃라인 확정은 별도 브랜드 자산 작업이다.

### 피오

노란 병아리 몸통, 두 장의 초록 새싹, 네이비 눈, 작은 주황 부리. 친근하지만 지나치게 유아적으로 표현하지 않는다. 얼굴의 형태와 새싹 비율을 유지한다.

- 작은 UI 피오: 32/40/48px. 정적 SVG를 사용한다.
- 안내·빈 상태: 64/80px. 대표 타임라인: 96–120px.
- 한 화면에서 주인공 피오는 한 곳에 둔다. 채팅 아바타는 기능상 반복할 수 있다.
- 홈에서는 현재 위치의 동반자로 배치한다. 같은 화면의 상단·하단·사이드바 응원 배너는 반복하지 않는다.
- 금융 데이터, 버튼, 경고 문구 위에 캐릭터를 겹치지 않는다.
- 이미지 시안의 입체 일러스트는 추후 별도 제작 대상이다. 이번 SVG는 작은 UI용 자산이며 원본 일러스트를 복제한 것이 아니다.

## 3. 색상 체계

원시 색상과 역할 색상을 분리한다. tokens.css가 실제 색상값의 기준이다.

| 역할 | 토큰 | 값 | 사용 |
|---|---|---|---|
| 브랜드 | green-500 | #20B26B | 워드마크, 장식, 성장의 인상 |
| 주요 행동 | green-600 | #008653 | 흰 글씨 버튼, 진행 막대 |
| 행동 hover / 긍정 텍스트 | green-700 | #006C43 | 버튼 hover, 완료·현재 라벨 |
| 제목 | navy | #102A43 | 제목, 중요 금액 |
| 본문 | text | #243D50 | 설명, 입력 내용 |
| 보조 텍스트 | muted | #526674 | 날짜, 출처, 보조 설명 |
| 배경 | canvas | #FCFBF6 | 앱 전체 |
| 카드 | surface | #FFFFFF | 금융정보·입력 |
| 구분선 | border | #E2E8E1 | 비상호작용 구분선 |
| 입력 테두리 | input-border | #7A8983 | 입력·보조 버튼 경계 |
| 기회 | yellow / yellow-bg / yellow-text | #FFD95A / #FFF7DB / #795600 | 피오, 인사이트, 목표 |
| 주의 | orange / orange-bg / orange-text | #FF8B3D / #FFF0E4 / #A44512 | 마감, 주의 |
| 예상 | blue-bg / blue-text | #EEF4FF / #365A93 | 예상 일정 |
| 오류 | danger / danger-bg | #B12D43 / #FFF0F2 | 입력 오류, 실패 |
| 풍경 | sky / meadow | #E6F7FA / #D9EFAD | 타임라인 일러스트만 |

밝은 초록·노랑·주황 위에 작은 흰 글씨를 올리지 않는다. 노랑·주황 상태는 짙은 전용 텍스트와 함께 쓴다. 확정·예상·목표는 ✓ / ◇ / ☆와 문구를 함께 사용한다. 준비도 색으로 좋은 재무 상태를 단정하지 않는다.

## 4. 타이포그래피

Pretendard 우선, Apple SD Gothic Neo → Noto Sans KR → system-ui 순으로 대체한다. 이 패키지에는 폰트 파일이 포함되지 않는다. 출시 시 사용할 폰트와 라이선스를 확정하고 자체 제공한다. 보드가 표시되는 기기에 따라 폰트가 달라질 수 있다.

| 용도 | 크기 / 행간 | 굵기 |
|---|---|---|
| 브랜드·소개 제목 | 40 / 52px | 800 |
| 페이지 제목 | 28 / 38px | 700–800 |
| 섹션 제목 | 20 / 28px | 700 |
| 카드 제목 | 16 / 24px | 700 |
| 본문·입력 | 16 / 26px | 400–500 |
| 보조 설명·버튼 | 14 / 22px | 400 / 700 |
| 날짜·배지 | 12 / 18px | 500–700 |

모바일 페이지 제목은 24/34px. 핵심 행동·금융정보는 14px 이상, 본문은 16px. 금액과 표 숫자는 tabular-nums를 사용한다. 짧은 한글 제목은 자간 -0.02em, 본문은 0. 줄바꿈은 단어 단위로 처리하되 긴 URL은 줄바꿈한다.

## 5. 공간·형태·레이아웃

- 간격: 4 / 8 / 12 / 16 / 20 / 24 / 32 / 48 / 64px.
- 입력·버튼 radius 12px, 카드 20px, 대표 풍경 영역 28px, 배지 pill.
- 카드 안쪽 24px, 모바일 20px. 카드 간격 16–24px. 섹션 간격 32–48px.
- 그림자는 cards 토큰 한 종류, Drawer는 overlay 한 종류. 테두리는 1px.
- 1280px 이상: 사이드바 200px + 본문 + Right Now 320–360px. 콘텐츠 최대 1440px, 바깥 여백 32px, 열 간격 24px.
- 768–1279px: 메뉴 축소 또는 상단 배치. Right Now를 별도 오른쪽 열로 강제하지 않고 타임라인 아래 배치한다.
- 767px 이하: 좌우 여백 16px, 단일 열, 하단 내비게이션 높이 64px + safe area. 타임라인 내부만 가로 스크롤한다. 홈 순서는 오늘 할 일 요약 → 타임라인 → 다가오는 이벤트.
- 320px 너비에서 페이지 전체의 가로 스크롤이 없어야 한다. 긴 비교표만 독립 스크롤 가능.
- 풍경은 타임라인 영역에서만 사용. 금융정보 카드에는 흰 바탕을 유지한다.

## 6. 핵심 컴포넌트 계약

| 컴포넌트 | 구성 | 상태 / 행동 |
|---|---|---|
| Button | 라벨, 선택 아이콘, 높이 ≥44px | primary / secondary / ghost, hover, pressed, focus, disabled, loading |
| Input | 항상 보이는 라벨, 입력, 도움말 | default / focus / error / disabled. 오류를 aria-describedby로 연결 |
| Navigation | 20–24px 선형 아이콘 + 라벨 | active는 연초록 배경·짙은 초록·aria-current. 색만으로 구별하지 않음 |
| Event node | 아이콘, 날짜, 제목, 확실성 배지 | 확정 / 예상 / 목표. 현재 마커는 별도 원형. 선택 시 상세 열기 |
| Fin checkpoint | 마름모 표식, 제목, 예정일, 상태 | 예정 / 완료 / 보류. Life Event와 모양으로 구분 |
| Right Now | 우선 라벨, 행동 제목, 이유, CTA | 최대 3개. 원인 이벤트와 연결. 카드당 주요 CTA 1개 |
| Readiness | 라벨, 값, 진행 막대, 산출 근거 | 알려진 값 / 정보 부족. 정보 부족을 임의 백분율로 표시하지 않음 |
| Opportunity | 제목, 기관, 관련 이유, 마감, 출처 | 모집 중 / 예정 / 마감 / 확인 필요. 신청 자격 확정 표현 금지 |
| Event Drawer | 제목·날짜, 준비도, 체크리스트, 기회, AI 연결 | PC 400px, 모바일 bottom sheet ≤90dvh. 닫기·ESC·포커스 복귀 |
| Decision | 추천, 동일 열 비교표, 이유, 가정·출처 | 추천 강조 1행. 계획 반영 전 변경 내용을 보여줌 |
| Pio message | 피오, 1–2문장, 선택 CTA | 안내 / 빈 상태 / 완료. 긴 대화는 일반 채팅 레이아웃 |

이벤트 카드 전체를 클릭 가능하게 만들 경우 중첩 버튼을 넣지 않는다. 개별 CTA가 여럿이면 카드 자체에는 클릭 동작을 두지 않는다. 클릭 가능한 체크리스트 한 행은 최소 44px.

## 7. 정보와 인터랙션 상태

- Loading: 레이아웃 크기를 유지하는 skeleton + 접근 가능한 ‘불러오는 중’ 설명. 로딩 버튼은 중복 제출을 막고 aria-busy를 제공한다.
- Empty: ‘아직 이벤트가 없어요’ + ‘첫 이벤트 추가’. 빈 화면을 0% 실패 상태로 표현하지 않는다.
- Error: ‘정보를 불러오지 못했어요’ + ‘다시 시도’. 성공한 다른 데이터까지 숨기지 않는다.
- Unknown: ‘준비도를 계산하려면 저축 정보를 알려주세요’ + 필요한 입력. ‘확인 필요’와 실제 모집 중을 구분한다.
- Completed: 체크 표시·완료 문구를 함께 노출. 취소 가능한 행동은 되돌리기를 제공한다.
- Motion: 색·배경 전환 160ms, Drawer 진입 240ms, 이동 최대 8px. 피오·현재 위치의 무한 반복 애니메이션은 사용하지 않는다. reduced-motion에서는 이동 효과를 제거한다.
- Focus: 짙은 초록 3px 외곽선 + 3px 간격. hover 효과만으로 상호작용을 알리지 않는다.
- Drawer: 열기 버튼에서 첫 컨트롤로 이동, 내부 포커스 유지, 배경 접근 차단, 닫은 뒤 원래 버튼으로 복귀.

## 8. 아이콘·풍경

기존 Icon.tsx의 SVG 선형 아이콘을 기반으로 통일한다. 기본 viewBox 24, stroke 1.75–2, 둥근 끝. 이벤트 타일은 40–48px 배경 위 20–24px 아이콘. 주요 메뉴에서 이모지와 서로 다른 아이콘 계열을 섞지 않는다.

풍경은 낮은 대비의 하늘·언덕·작은 나무·얇은 길로 구성한다. 길은 시간 흐름을 보조하며 사건의 순서가 우선이다. 텍스트가 놓이는 곳에는 충분한 단색 영역을 확보한다. 실제 날짜 간격에 비례하지 않는 타임라인은 순서형임을 명확히 하고 실제 연도 눈금처럼 표현하지 않는다.

## 9. 현재 코드에 적용하는 순서

1. globals.css에 의미 토큰을 연결한다. 기존 fin-green-500을 일괄 변경하지 말고 브랜드와 버튼 역할을 분리한다.
2. Brand.tsx의 워드마크 색 순서를 시안과 맞춘다. 피오는 용도별 크기를 제한한다.
3. Button / Badge / Input / Card / Readiness 공통 요소를 만든 후 각 페이지의 중복 스타일을 교체한다.
4. 홈의 정보 우선순위·타임라인 풍경·이벤트 상세를 적용한다.
5. 모바일·키보드·긴 한글·빈 데이터·API 실패 상태를 확인한다.

기존 토큰 매핑: canvas → --tf-canvas; surface → --tf-surface; ink-900 → --tf-navy; ink-700 → --tf-text; ink-500 → --tf-muted; fin-green-500 → 브랜드는 --tf-green-500, 버튼은 --tf-green-600; fin-orange → 장식은 --tf-orange, 글씨는 --tf-orange-text.

## 10. 납품 범위와 확인

- design-system.html: 반응형 브랜드·UI 보드. 버튼, 입력 검증, 체크리스트 예시는 보드 내부에서만 동작한다.
- tokens.css: 프레임워크 독립 CSS 토큰·기본 컴포넌트.
- tokens.json: 같은 토큰의 도구 연동용 값 목록.
- wordmark.svg / pio.svg: 편집 가능한 기초 SVG 자산.
- contrast-report.json: 지정된 텍스트/배경 조합의 계산 결과. 전체 제품 접근성 인증은 아니다.

아직 하지 않은 작업: 제품 전체 화면 적용, 완성형 입체 피오 일러스트, 전용 폰트 번들링, 실제 데이터 기반 준비도 로직 변경. 이는 디자인 시스템과 별도의 후속 구현이다.
